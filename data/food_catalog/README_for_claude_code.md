# Каталог блюд, перекусов и напитков — инструкция для Claude Code

Справочник готовых блюд, закусок, перекусов и напитков на русском языке: 35 групп (кухни мира + перекусы + соусы + напитки), **2244 позиции**, из них 206 алкогольных.

## Файлы

| Файл | Назначение |
|---|---|
| `catalog.json` | Основной файл. `meta` (счётчики), `items` (плоский список), `tree` (тип → кухня → категория → названия) |
| `catalog.csv` | Те же `items` для импорта в БД/таблицы (UTF-8 с BOM, теги через `\|`) |
| `CATALOG.md` | Человекочитаемая версия |
| `catalog_source.txt` | Исходник: правьте его, а не JSON |
| `build_catalog.py` | Пересборка: `python3 build_catalog.py` |

## Схема записи (`items[]`)

```json
{
  "id": "uzbek__plov_tashkentskiy",
  "name": "Плов ташкентский",
  "type": "cuisine",              // cuisine | snacks | drinks
  "cuisine_id": "uzbek",
  "cuisine": "Узбекская",
  "region": "Средняя Азия",
  "category": "Основные блюда",
  "is_alcoholic": false,
  "age_restricted": false,        // true для алкоголя: требуется проверка 18+/21+
  "tags": ["баранина"]            // авто-теги по ключевым словам (см. ниже)
}
```

- `id` уникален и стабилен (транслит + префикс группы), годится как первичный ключ.
- Одно и то же `name` может встречаться в разных группах (например, «Картофель фри» в американской кухне и в перекусах, «Мимоза» — салат и коктейль). Для поиска без дублей группируйте по `name.lower()`.
- `tags` — эвристика: курица, говядина, баранина, свинина, конина, рыба, морепродукты, сыр, грибы, тофу/вег, сладкое, острое. Это не диетическая маркировка: для халяль/веган/аллергенов нужна ручная разметка.

## Формат исходника

```
@ id_группы | Название группы | тип | регион
# Категория
Позиция 1; Позиция 2; Позиция 3
```

## Идеи для использования

1. Таблицы `cuisines`, `categories`, `items` (+ `item_tags`) в БД; сид из `catalog.json`.
2. Поиск: полнотекстовый по `name` с нечётким совпадением (триграммы / Fuse.js), фильтры по `type`, `cuisine`, `category`, `tags`.
3. Скрывать позиции с `age_restricted: true`, пока возраст не подтверждён; учитывать местные правила продажи алкоголя.
4. Для мультиязычности добавить поля `name_en`, `name_uz` (каталог сейчас только на русском).
5. Цены, фото, КБЖУ и состав в каталоге отсутствуют — это поля для следующего этапа.
